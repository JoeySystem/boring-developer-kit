# BORING Developer Kit

BORING 开发者预览计划：让用户通过扩展和设备协议，定义自己的设备使用方式。

## 当前状态

开发者交付准备中。当前仓库仅包含项目介绍、维护政策和授权状态说明，尚未发布 SDK、协议文件、示例或可下载的开发包。

首期计划提供：

- Python 扩展 SDK 源码；
- 扩展格式、本地 API 和设备事件文档；
- 观察事件、处理绑定动作和提交按键映射提案的示例；
- 设备通信协议及配置 Schema；
- 入门说明、必要的开发与构建说明、版本对应关系和已知限制。

首期推荐使用配套官方 BORING Console 运行 Python 扩展。原始协议作为进阶开发参考；第三方上位机和个性化环境适配按社区自行开发处理。已发布版本会明确标注支持的平台及对应的控制台、固件版本。

## 开放范围

本仓库用于交付开发接口、示例和文档。完整固件、完整控制台产品源码、生产与签发工具、真实生产记录、密钥及品牌资产不属于首期交付范围。

## 授权

计划采用非商业源码开放、商业复用另行书面授权的模式。具体许可仍在整理；本仓库当前没有提供 SDK 或其他产品代码的使用授权，也没有采用 MIT、Apache 或 GPL 许可证。

源码可见不代表可以任意使用。正式授权范围以相关文件发布时附带的许可为准。参见 [授权状态](LICENSING.md)。

## 维护与反馈

项目按 Best Effort 方式维护，不承诺固定的 Issue 响应、PR 审阅、合并或发布时间。产品固件、桌面端、量产和更新链路的稳定性优先。

详细范围见 [维护政策](SUPPORT.md)。

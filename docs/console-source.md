# 社区控制台源码

`v0.1.0-preview.3` 新增 `console/`，让用户能够阅读、修改和运行完整的电脑端控制台，而不仅是调用 SDK。

## 来源与版本

- 来源产品版本：BORING Console `0.1.6`。
- 来源已提交快照：`1b0b16b28ddf69fafa8a2621331a69bc49df30c9`，2026-09-11。
- 公开构建名称：**BORING Console Community**。
- SDK `1.0.0`，本地扩展 API `1.0`，保持不变。
- 参考硬件与固件：Power V2，`20260910.07-g7989ccbf-dirty / sample-verified`。

来源提交用于说明出处，运行和构建本仓库不需要访问私人仓库或获取其 Git 历史。这不是仍在开发的 0.1.10 快照，也不是官方安装包的重新发布。

## 本次公开什么

公开控制台应用代码，包括界面、配置与映射编辑、提示词和宏、设备预览、扩展管理、Runner、本地 API、USB / BLE 通信及设备身份验证。提供对应测试、构建工具和开发说明。完整固件源码、固件镜像、量产与身份签发工具不在本开发包中。

社区版继续验证设备证书和随机挑战。生产根公钥以及验证算法不是生产私钥；公开这些内容不包含签发或复制官方设备身份所需的材料。配置写入与固件更新继续使用程序中的确认流程，源码开放不等于扩展 SDK 获得原始写设备接口。

## 公开分发适配

社区构建以系统字体替代内部 BORING 5R 字库，不附官方应用图标。字体度量和品牌外观可能与官方安装版不同；修改后的程序应标明社区来源，不表述为官方发布。

社区版的应用设置、本地服务、登录启动项和 Claude Hook 记录与官方版分开。本轮还修复了灯光工作区及窄窗设置页切换布局后未及时刷新控件位置的问题。

协议、Schema、公开认证向量和根公钥使用本仓库提供的资料。公开工程的运行、测试和构建入口见 [console/README.md](../console/README.md)。

## 开发与打包

从仓库根目录创建 `console/.venv`，使用 Python 3.12 安装本地 SDK 和控制台。原生打包脚本也使用这个虚拟环境路径：

```bash
python3.12 -m venv console/.venv
source console/.venv/bin/activate
python -m pip install -e ./sdk/python -e './console[test]'
python -m pip install -r requirements-dev.txt
```

启动参数、模拟设备模式和测试命令以 [控制台 README](../console/README.md) 为准。构建源码 wheel：

```bash
python -m pip wheel --no-deps --wheel-dir dist ./console
```

`--no-deps` 不把运行依赖装入 wheel；首次准备构建后端和运行依赖仍可能需要联网。构建无需私人源码、生产凭据、真实设备或固件刷写。wheel 不是 DMG / EXE；原生安装包构建与验收需要对应平台，本发布不承诺未经验证的平台组合。

## 稳定性和支持范围

本次选择明确的 0.1.6 来源版本进行公开适配，固件参考保持 `.07`。官方历史安装版的连接与更新验收、社区源码自动化测试、扩展示例实机验收是不同结果；本轮证据统一见 [发布验证](verification.md)。未完成的项目不因源码可构建而自动通过。

修改电脑端功能通常无需改写固件；增加固件尚未提供的事件或设备行为，需要另行开发，不能仅修改 SDK 获得。固件业务模块与完整工程的开放留待后续评估。

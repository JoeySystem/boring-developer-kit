# 控制台源码

Console **0.1.46** 的可公开应用代码于 `v0.1.0-preview.8` 同步；`preview.9` 未修改控制台源码，用户仍可修改并运行电脑端控制台。

## 来源与版本

- 来源状态：2026-09-15 已完成 0.1.46 macOS 安装版、USB 认证及两次配置写入/读回验收的源码状态；公开仓库提交保存本次精确快照。
- 公开程序标识：**BORING Console Community**；SDK `1.0.0` / 本地 API `1.0` 不变。
- 官方公开安装包仍为 [0.1.13 Apple Silicon Mac 测试版](install-console.md)。本次没有发布 0.1.46 DMG / EXE。

运行本仓库不需要私人仓库、内部构建产物或其 Git 历史。

## 本轮同步

- 功能键与状态灯键边界：NORMAL 模式下六个功能键、旋钮和摇杆可编辑；六个状态灯键保留给 Agent 状态。界面、扩展提案、草稿 API 和配置导入统一拒绝修改状态灯键，不能绕过后进入设备写入。
- 六个功能键支持逐键灯光修改；圆屏补读、配置验证和写入事务互斥，写入成功后按新 generation 重建页面状态，连续修改可再次应用。
- “应用到设备”一次点击后继续使用原有设备验证、写入、激活和配置读回确认，不跳过 generation 冲突保护。
- 断线后优先立即尝试已知端口并加快轮询；旧固件蓝牙认证失败仍停止反复重连并提示改用 USB。
- 固件来源按已验签发布记录识别；自定义或来源未确认的固件不会自动比较版本，但可以主动查看并恢复官方签名包。公开构建不预置官方发布记录。
- 桌面与固件更新提示、六小时后台检查和同版本 24 小时稍后提醒逻辑已经同步；公开构建的应用与固件在线源仍为空，不连接官方服务。
- 蓝牙名称、离线草稿、三语言 JSON 文案、扩展提案、固件签名校验和 macOS/Windows 更新客户端继续保留。SDK 不因此获得固件更新或任意输入流接口。

## 公开适配

使用系统字体、独立设置、单实例、本地扩展服务、登录项和 Claude Hook 路径，避免与官方版混用。保留设备证书与挑战认证、配置确认和固件签名校验；仅发布根公钥，不包含生产私钥和身份签发工具。

英文和日文的保存按钮在系统字体下改为上下排列，避免窄侧栏压缩文字；短屏上的设备示意按可视区高度缩放，滚动后可以完整看到设备。语言事件过滤器也避免再把销毁中的 Qt 对象传给默认过滤器。

设备图采用简单 Qt 控件示意，保留选中、缩放、灯光预览和编辑交互。**不附内部 Blender/STEP 模型、品牌字库、官方图标、固件屏幕素材或 Companion 操作动画。** 保留文字引导；示意屏幕不是设备屏幕实时镜像。

`app-update-source.json`、`firmware-source.json` 留空。公开构建不会自动更新成官方应用；需要自行维护更新渠道时，使用自己的 URL、签名密钥与应用标识。没有配置时可从源码仓库获取代码更新，原生打包不需要官方发布凭据。见 [应用更新开发说明](desktop-updates.md)。

## 固件与验收边界

固件源码从 preview.6 起在 [firmware](../firmware/README.md) 中单独公开；官方镜像、生产与签发工具不在开发包中。`.07` 是历史兼容参考；新蓝牙名称要求设备声明 `ble_name` 能力。`preview.9` 固件源码按功能参考 `20260916.01-gbc6d2699-dirty / sample-verified`；该签名官方镜像仅作为独立[维护 ZIP](official-firmware-20260916.01.md) 附件提供。

官方固件入口要求签名维护包，历史无发布者签名的 ZIP 会被拒绝。自定义固件导入代码存在，不代表可以恢复任何损坏固件；完整 DIY 安装和恢复尚未完成实机验收，**不能据此承诺任意改动都可恢复**。USB、认证、更新等基础模块坚决不要改。见 [固件维护边界](firmware-maintenance.md)。

本轮源码测试、独立解压安装和模拟设备启动结果见 [发布验证](verification.md)。它们不替代安装包更新、实机刷写、蓝牙重连或 Windows 验收。

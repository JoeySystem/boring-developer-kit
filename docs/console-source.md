# Console 0.2.3 社区源码

本次 `v0.1.0-preview.11` 把控制台公开源码从 0.2.1 同步到 0.2.3。0.2.3 是在官方 0.2.1 发布代码上只修一处的正式补丁版：蓝牙连接时，回复数据还在陆续到达就继续计时（总上限 60 秒），修复设备配置较多（约 9.6 KB 以上，常见于选了 5 套左右常用 AI）时读配置超时、一直连接失败的问题。其余功能与 0.2.1 相同。公开提交保存社区适配结果，没有导入私人 Git 历史。

包含配置编辑与写入读回、USB/BLE 连接、离线草稿恢复、语音应用设置、工作流、扩展运行、SDK 1.1.0 / API 1.1 与所需协议，以及四个扩展示例。

社区版使用 BORING Console Community 独立设置、系统字体和公开的二维设备示意。连接提示、语音配置和蓝牙切换帮助均使用该示意；操作引导提供文字，不附官方演示动画。代码中的品牌名称不意味着品牌素材授权。

保留设备认证、配置冲突与写入确认、固件签名验证。应用构建来源为 custom，软件与固件在线源留空，不能自动替换官方安装版。不包含生产私钥、设备私密数据、部署配置、生产签发工具、品牌字库、官方图标、Blender/STEP/QML 产品模型或屏幕素材。

私有仓库里还在开发、尚未发布的控制台新版本（新界面、桌面 Agent 状态、第三方应用联动等）不在本次同步范围，等正式发布后再同步。

固件源码本次同步到 20261118.01。该固件的“双击旋钮切换模式”等新行为由设备自身处理，0.2.3 按设备报告的能力显示功能；固件新增的协议命令 0.2.3 不使用。官方安装包与社区源码分别交付；源码 wheel 不是 DMG/EXE。

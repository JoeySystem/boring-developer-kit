# Console 0.2.1 社区源码

本次 `v0.1.0-preview.10` 同步控制台 0.2.1 已提交发布源码的可公开部分。公开提交保存精确的社区适配结果；没有导入私人 Git 历史。

包含配置编辑与写入读回、USB/BLE 连接、离线草稿恢复、语音应用设置、工作流、扩展运行、SDK 1.1.0 / API 1.1 与所需协议。四个扩展示例包含新增的 `save_host_task`。

社区版使用 BORING Console Community 独立设置、系统字体和公开的二维设备示意。连接提示、语音配置和蓝牙切换帮助均使用该示意；操作引导提供文字，不附官方演示动画。代码中的品牌名称不意味着品牌素材授权。

保留设备认证、配置冲突与写入确认、固件签名验证。应用构建来源为 custom，软件与固件在线源留空，不能自动替换官方安装版。不包含生产私钥、设备私密数据、部署配置、生产签发工具、品牌字库、官方图标、Blender/STEP/QML 产品模型或屏幕素材。

固件仍是 preview.9 的历史公开源码参考 20260916.01，本次没有同步或发布新固件。官方安装包与社区源码分别交付；源码 wheel 不是 DMG/EXE。

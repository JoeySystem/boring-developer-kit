# 控制台源码

`v0.1.0-preview.5` 同步 Console **0.1.24** 的可公开应用代码，用户可以修改并运行电脑端控制台。

## 来源与版本

- 来源快照：`333b6fb103d864243d602a45056138184e235521`，2026-09-13。
- 公开程序标识：**BORING Console Community**；SDK `1.0.0` / 本地 API `1.0` 不变。
- 官方公开安装包仍为 [0.1.13 Apple Silicon Mac 测试版](install-console.md)。本次没有发布 0.1.24 DMG / EXE。

来源提交仅说明出处，运行本仓库不需要私人仓库或其 Git 历史。

## 本轮同步

- 蓝牙自定义名称：按固件能力显示，区分已保存名称与实际生效名称，保留失败输入并读回确认；改名不依赖旧广播名称发现设备。
- 配置事务和恢复：设备外部配置变化检测、离线草稿、更新前退出与重启恢复、UTF-8 字节边界处理。
- 中文、英文、日文统一 JSON 文案目录，翻译资源随包提供；旧 TS/QM 不再是运行时文案来源。
- 映射编辑和设置帮助、诊断技术信息折叠、多个页面共用可交互控件示意，改善选中、缩放和键盘可访问性。
- 固件发布者 Ed25519 签名验证；自定义固件与官方包分开识别、确认和兼容判断，签名失败不会自动降级为自定义包。
- macOS / Windows 应用更新客户端、取消与草稿恢复代码，以及构建时的可选更新配置；默认不配置服务。
- WMP1 蓝牙名称命令、能力字段、UTF-8 长度限制及公开样例同步。SDK 不因此获得固件更新或任意输入流接口。

## 公开适配

使用系统字体、独立设置、单实例、本地扩展服务、登录项和 Claude Hook 路径，避免与官方版混用。保留设备证书与挑战认证、配置确认和固件签名校验；仅发布根公钥，不包含生产私钥和身份签发工具。

英文和日文的保存按钮在系统字体下改为上下排列，避免窄侧栏压缩文字；短屏上的设备示意按可视区高度缩放，滚动后可以完整看到设备。语言事件过滤器也避免再把销毁中的 Qt 对象传给默认过滤器。

设备图采用简单 Qt 控件示意，保留选中、缩放、灯光预览和编辑交互。**不附内部 Blender 模型、品牌字库、官方图标、固件屏幕动画或 Companion 操作动画。** 保留现有文字引导；示意屏幕不是设备屏幕实时镜像。

`app-update-source.json`、`firmware-source.json` 留空。公开构建不会自动更新成官方应用；需要自行维护更新渠道时，使用自己的 URL、签名密钥与应用标识。没有配置时可从源码仓库获取代码更新，原生打包不需要官方发布凭据。见 [应用更新开发说明](desktop-updates.md)。

## 固件与验收边界

固件源码从 preview.6 起在 [firmware](../firmware/README.md) 中单独公开；官方镜像、生产与签发工具不在开发包中。`.07` 是历史兼容参考；新蓝牙名称要求设备声明 `ble_name` 能力。当前固件源码参考为 `20260914.03-gbc6d2699-dirty / sample-verified`，它不是本仓库新增的可下载固件镜像。

官方固件入口要求签名维护包，历史无发布者签名的 ZIP 会被拒绝。自定义固件导入代码存在，不代表可以恢复任何损坏固件；完整 DIY 安装和恢复尚未完成实机验收，**不能据此承诺任意改动都可恢复**。USB、认证、更新等基础模块坚决不要改。见 [固件维护边界](firmware-maintenance.md)。

本轮源码测试、独立解压安装和模拟设备启动结果见 [发布验证](verification.md)。它们不替代安装包更新、实机刷写、蓝牙重连或 Windows 验收。

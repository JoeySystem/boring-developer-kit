# 公开同步验证 · preview.11 · 2026-11-24

范围：控制台社区源码 0.3.0、协议资料、Power V2 固件源码 20261123.01、固件更新与校准工具源码（run37）。全部在 Apple Silicon macOS 上验证，没有 Windows 原生构建或实机测试。

## 控制台 0.3.0 社区源码

- 来源是私有仓库已发布的 0.3.0（与公开 Release `console-v0.3.0` 安装包同一版本）。社区适配沿用 0.2.1 的做法，用三方合并把原有社区改动带到 0.3.0，再处理新增的官方专有内容（见 [源码说明](console-source.md)）。
- 全量测试（`console/tests` 与仓库 `tests/`，Python 3.12，无窗口模式，6 个进程并行）：**3229 通过、1 失败、64 跳过**，没有进程崩溃。
- 对照：同一环境下跑私有 0.3.0 自己的测试，3685 通过、2 失败、31 跳过。社区版唯一的失败 `test_ui_stability_smoke::test_repeated_navigation_resize_and_reconnect` 在私有版同样失败，不是社区适配引入的。
- 社区版少掉的测试：只覆盖未公开内容的测试文件没有收入（豆包联动内部、Chromium 本地存储读取、3D 模型与渲染、新手引导动画素材、内部豆包验收包、更新密钥连续性，共 26 个文件）；另有 15 处测试因检查官方专有内容被标为跳过并写明原因（内置官方发布记录为空、不内置恢复固件、固件在线源留空、3D 模型内部状态、连接动画片段、只能打社区包等）。
- 适配中发现并修好的问题：新的 Mode 页放大动画要读点阵字的点位，社区版改用系统字体采样出点位；新手引导用到的图标是 Phosphor Icons（MIT），随许可一起收入，否则打开引导会出错；macOS 打包脚本补回最低系统版本 13.0 等三行。
- 实际启动：`controller_config.app.main(["--demo", "ready"])` 在模拟设备下打开主窗口，标题为 BORING Console Community，版本 0.3.0。
- 没做：DMG / EXE 原生打包、真实设备连接、蓝牙、实体按键、固件写入。

## 本次示例修正

原始提案示例提交后立即退出，控制台会因为扩展不再就绪而阻止用户批准。公开版增加等待连接结束的循环，让用户有时间审阅；停用示例时由控制台结束进程。已验证用户批准后只进入本地草稿，设备写入仍需原有确认流程。

此修正位于公开示例，未改动产品固件或控制台实现。公开协议测试向量删除测试私钥字段，保留公钥验证所需数据。两个官方生产根公钥单独提供，不包含任何生产私钥。

## 用户可以复跑的部分

在仓库或完整开发包根目录，使用已安装 SDK 和 `requirements-dev.txt` 的虚拟环境运行：

```bash
python -m pytest -q
python -m pip wheel --no-deps --wheel-dir dist ./sdk/python
python tools/build_release.py --output dist
```

独立测试和打包不依赖私有项目路径或设备。控制台联合测试需要内部宿主源码，因此不作为本仓库可独立运行的测试发布。

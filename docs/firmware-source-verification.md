- 在独立公开仓库目录使用 ESP-IDF **6.0.2** 实际构建 `matrix12-power-v2-codex-usb --custom-name publiccheck` 成功。依赖由组件管理器获取，未使用私有固件目录中的构建产物。
- 生成 `custom-publiccheck-20260914.01-g9c95d08e-dirty`，产品版本 `0.3.0-alpha.1`，应用镜像 **1,140,368 字节**。其中 Git 编号来自构建时的公开仓库工作树，不冒充官方构建。
- 自定义 ZIP 检查通过：只含应用镜像与 manifest，`origin=custom`、`validation_state=built`、最低控制台版本 0.1.24，镜像中包含同一 custom 构建编号。此测试镜像不作为官方固件分发。

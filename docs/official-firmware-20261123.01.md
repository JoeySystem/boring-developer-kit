# BORING MIST 官方签名固件 20261118.01

[下载 `Firmware-BORING-20261118.01.zip`](https://github.com/JoeySystem/boring-developer-kit/releases/download/mist-recovery-20261118.01/Firmware-BORING-20261118.01.zip)。这是 Power V2 的**官方签名应用固件维护包**，在 BORING Console 的“导入官方固件”里使用；不是源码 ZIP，也不是通用 ESP32 烧录包。同一 Release 里的[固件更新与校准工具](../recovery-tool/README.md)内置同一份固件。

- 适用硬件：`WMP-S3-MATRIX12-POWER-V2`；Build ID：`20261118.01-gf1f54815`；产品版本：`0.3.0-alpha.1`；SHA-256（ZIP）：`7358fae4bb6f91cf92c04cfe4ce3068bd289b96d4a6a8b905d4f3206971dc86e`。
- 渠道和验证状态：`sample / sample-verified`，是当前样机权威包，未标记为正式量产稳定版，也尚未放进在线更新源。
- 主要变化：双击旋钮在普通和 Codex 之间切换，双击摇杆不再切换模式，Claude Code 模式移出双击循环；充满电显示 100%；摇杆单次异常采样不再算作一次方向输入；畸形配置请求不再导致重启。此前各版改动见 [CHANGELOG](../CHANGELOG.md)。

## 怎么装

用支持官方固件导入的 BORING Console（官方 0.2.x），通过 USB 连接匹配硬件，选“导入官方固件”，选择**整个 ZIP**，安装后读回上述 Build ID。不要解压后单独刷 `.bin`，不要选“导入自定义固件”，不要使用整片擦除流程。

## 验证范围

- Power V2 样机（一台）：从 20261113.01 经 USB 升级、从更老的 20261110.01 经 Console 导入本 ZIP 升级，两种路径都读回正确版本，配置代数和摘要不变，蓝牙配对保留，没有待回滚。
- 手测：蓝牙回连、第 8 键单击说话和双击发送、摇杆方向与按下、双击旋钮切模式、满电显示 100%。
- 官方包签名经 Console 内置公钥验证通过，篡改版本号、哈希、大小或说明都会被拒。

## 已知限制

- Console 通过在线更新源下载本包的路径没有实测（本包尚未放进更新源）。
- 只用 Console 0.2.2 测过；0.2.1、0.2.3 连接本固件没有逐项实测。
- 设备插着数据线、电脑睡眠时可能反复唤醒电脑，醒来后配置通道可能不应答，拔插数据线即可恢复。本版不修。
- 2026-10-16 之前出厂配置的设备，第 8 键仍是空格，固件不自动迁移；[固件更新与校准工具](../recovery-tool/README.md)会把它改成说话/发送手势。
- 满电判定点只用一台样机标定。配置上限 16384 字节，出厂大小的方案最多 7 套。

安装交付包 `BORING-Console-0.1.13-macOS-arm64.zip` 内含同版本 **DMG、安装说明和第三方许可资料**。安装控制台不需要先安装 Python，也不需要编译源码。该包不含固件镜像，不能导入“固件维护”。

## 适用范围

- 适用于 Apple Silicon（M 系列）Mac；本次已验收环境为 macOS 26.6.2。
- 未提供 Windows、Linux 或 Intel Mac 安装包；其他 macOS 版本尚未逐项验收，不作最低系统版本承诺。
- 这是 BORING 官方提供的 **0.1.13 测试版安装包**，尚未完成全部交付场景验收。
- 配套参考为 Power V2 / `.07 sample-verified` 固件。软件安装不会自动更新设备固件。
- 当前公开控制台源码同样基于 0.1.13，使用系统字体及独立配置适配。Release 自动生成的 “Source code” 下载是公开仓库快照，不是安装文件；要直接安装请下载本页安装交付 ZIP。

## 安装或替换旧版

1. 下载上方安装交付 ZIP 并解压，打开其中的 `BORING-Console-0.1.13-macOS-arm64.dmg`。
2. 如果旧版正在运行，先通过应用菜单退出 BORING Console；仅点窗口关闭按钮可能仍在后台运行。有未保存配置时，先处理原窗口的保存／放弃提示。
3. 将 `BORING Console.app` 拖入“应用程序”。更新已有版本时替换应用，不需要手动删除用户设置、草稿或缓存目录。
4. 从“应用程序”启动，进入“设置 → 关于”，确认版本为 **0.1.13**。安装后可以推出 DMG。
5. 首次建议使用 USB 数据线连接设备，等待身份认证和配置读取完成。不要同时运行两个控制台或其他占用同一设备串口的工具。

### 首次打开提示

本包使用 ad-hoc 签名，**尚未取得 Developer ID 签名或 Apple 公证**。如果 macOS 提示无法验证开发者，在确认文件来自上述官方仓库后，可依照 [Apple 的官方说明](https://support.apple.com/zh-cn/102445)，在尝试打开后进入“系统设置 → 隐私与安全性”，对这个应用选择“仍要打开”。不需要关闭系统整体安全检查。

如果系统明确报告恶意软件或文件损坏，请保留完整提示并联系官方，不要将所有提示都当成同一种未公证提示处理。按实际使用需要授权蓝牙或电脑端动作所需权限；不用为了 USB 配置预先开放所有权限。

## 本版变化与已知限制

本版同步离线工作区、配置应用流程、快捷键录制与模式提示、响应式布局及设备控件比例修复。选中按键、旋钮或摇杆后不再被旧样式压扁；菜单栏可选择显示方式。

已完成：从本轮 0.1.13 DMG 实际安装并启动、USB 生产身份认证与配置读取、最大化／恢复、按键／旋钮／摇杆选择及隐藏重开时的控件比例。0.1.12 轮次已在原生安装版验证 Command+N 与 Control+N 录制显示，未写设备配置。上传前重新核对 0.1.13 包内版本、arm64、签名完整性、生产认证策略及 Runner。

当前 `.07` 固件没有新电量字段时显示“—”；电量配套固件仍是候选。充电状态没有经验证的硬件信号，不根据 USB 连接或 100% 电量猜测。

尚未完成：三个扩展示例在本安装包中的完整实体触发、绑定回退、提案写入／读回；本版 USB 拔插后手动写入、NORMAL 快捷键实际物理执行、纯蓝牙重连与完整固件更新链路；干净电脑和其他平台实测。旧版验收和历史公开源码测试不能替代这些结果。

若设备仍是首批 `.16` 固件，旧固件更新继续按原官方 USB 更新指引进行；本轮没有重新验收 `.16 → .07` 全流程，也不提供新固件。需要维护包时，通过原有官方交付渠道获取。

## 尝试扩展与反馈

反馈时提供软件版本、macOS 版本、连接方式及复现步骤即可；请移除日志中的私人内容和完整设备标识。支持范围按 [Best Effort](../SUPPORT.md)。

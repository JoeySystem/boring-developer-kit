安装交付包 `BORING-Console-0.1.11-macOS-arm64.zip` 内含同版本 **DMG、安装说明和第三方许可资料**。安装控制台不需要先安装 Python，也不需要编译源码。该包不含固件镜像，不能导入“固件维护”。

## 适用范围

- 适用于 Apple Silicon（M 系列）Mac；本次已验收环境为 macOS 26.6.2。
- 未提供 Windows、Linux 或 Intel Mac 安装包；其他 macOS 版本尚未逐项验收，不作最低系统版本承诺。
- 这是 BORING 官方提供的 **0.1.11 测试版安装包**，尚未完成全部交付场景验收。
- 配套参考为 Power V2 / `.07 sample-verified` 固件。软件安装不会自动更新设备固件。
- 当前公开控制台源码基于 0.1.6，和本安装包独立版本管理。本次没有公开 0.1.11 的完整源码；Release 自动生成的 “Source code” 下载也是公开仓库快照，不是 0.1.11 安装文件。

## 安装或替换旧版

1. 下载上方安装交付 ZIP 并解压，打开其中的 `BORING-Console-0.1.11-macOS-arm64.dmg`。
2. 如果旧版正在运行，先通过应用菜单退出 BORING Console；仅点窗口关闭按钮可能仍在后台运行。有未保存配置时，先处理原窗口的保存／放弃提示。
3. 将 `BORING Console.app` 拖入“应用程序”。更新已有版本时替换应用，不需要手动删除用户设置、草稿或缓存目录。
4. 从“应用程序”启动，进入“设置 → 关于”，确认版本为 **0.1.11**。安装后可以推出 DMG。
5. 首次建议使用 USB 数据线连接设备，等待身份认证和配置读取完成。不要同时运行两个控制台或其他占用同一设备串口的工具。

### 首次打开提示

本包使用 ad-hoc 签名，**尚未取得 Developer ID 签名或 Apple 公证**。如果 macOS 提示无法验证开发者，在确认文件来自上述官方仓库后，可依照 [Apple 的官方说明](https://support.apple.com/zh-cn/102445)，在尝试打开后进入“系统设置 → 隐私与安全性”，对这个应用选择“仍要打开”。不需要关闭系统整体安全检查。

如果系统明确报告恶意软件或文件损坏，请保留完整提示并联系官方，不要将所有提示都当成同一种未公证提示处理。按实际使用需要授权蓝牙或电脑端动作所需权限；不用为了 USB 配置预先开放所有权限。

## 本版变化与已知限制

本版改善按键配置页的窗口缩放、设备图比例、编辑区空间和保存按钮位置，避免缩放或连接完成后控件位置再次跳动。

已完成：从本轮 DMG 实际安装并启动、USB 生产身份认证与配置读取、普通窗口／最大化／恢复、选中按键后的编辑对象保留，以及中英文布局观察。上传前重新核对 DMG 中版本、arm64 可执行文件、签名完整性、生产认证策略和扩展 Runner；实际运行包内 Runner，在清除 PYTHONPATH 的环境下成功导入 SDK API 1.0 与 Qt 6.11.1。

已知问题：先用中文打开按键编辑，再切换英文，部分快捷键预览和无障碍名称仍可能保留中文；不改变原 HID 映射。当前 `.07` 固件未返回本版新增电量字段时，电量显示“—”，不会因安装软件自动获得该字段。

尚未完成：三个扩展示例在本安装包中的完整实体触发、绑定回退、提案写入／读回；本版 USB 拔插后手动写入、纯蓝牙重连与完整固件更新链路；干净电脑和其他平台实测。旧版验收和公开源码的 983 项测试不能替代这些结果。

若设备仍是首批 `.16` 固件，旧固件更新继续按原官方 USB 更新指引进行；本轮没有重新验收 `.16 → .07` 全流程，也不提供新固件。需要维护包时，通过原有官方交付渠道获取。

## 尝试扩展与反馈

连接完成后可以按 [开始使用](../START-HERE.md) 阅读示例导入流程；API 1.0 / SDK 1.0.0 的源码和包内 Runner 已存在，但不将上述尚未完成的实体触发路径表述为稳定承诺。只有需要修改控制台本身时才使用源码开发包。

反馈时提供软件版本、macOS 版本、连接方式及复现步骤即可；请移除日志中的私人内容和完整设备标识。支持范围按 [Best Effort](../SUPPORT.md)。

安装包内第三方组件保持各自许可；随包附许可文本与上游来源。公开源码许可不改变已购官方产品的正常使用权，也不授权提取品牌字体、图标用于其他产品。

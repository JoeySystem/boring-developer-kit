# 首期开放范围

BORING 开发者计划首先开放电脑端扩展能力，让用户决定设备触发后执行什么个人动作和流程。固件、SDK 和控制台仍在调整，具体接口以实际发布版本为准。

## 计划交付的内容

| 内容 | 用途 | 当前状态 |
|---|---|---|
| 开发者说明与维护政策 | 理解范围、参与方式和支持边界 | 文档已公开 |
| Python 扩展 SDK | 读取上下文、接收事件、处理动作和提交映射提案 | 尚未发布源码 |
| 三类扩展示例 | 观察事件、处理绑定动作、提交映射提案 | 尚未发布示例包 |
| 设备协议与配置 Schema | 为进阶通信开发提供参考 | 尚未发布文件 |
| 版本对应和开发说明 | 指明适用控制台、固件、平台及运行方式 | 发布状态已说明；具体组合待交付 |

## 首期推荐路径

用户通过官方控制台导入本地 Python 扩展，由控制台管理运行、绑定和设备会话。扩展根据公开接口接收语义事件、执行自定义动作、提出配置建议。

当前准备中的扩展围绕提示词槽位触发展开。这里的“提示词”是设备已有的触发入口；扩展可以围绕收到的内容设计自己的电脑端流程。

以下能力不属于首期扩展接口承诺：

- 每次普通按键按下或释放、旋钮转动、摇杆输入的通用事件流；
- 任意绘制屏幕页面或直接控制所有灯光、马达行为；
- 改写设备内部工作模式；
- 直接写设备配置、执行固件更新或绕过控制台的用户确认。

协议中存在某条命令，并不代表 SDK 已提供对应方法，也不代表全部固件版本都支持它。

## 首期保留的内容

- 完整固件和完整控制台产品源码；
- 生产签发、烧录、整机验收和标签等内部工具；
- 私钥、签名与部署凭据、真实生产台账、设备备份和客户数据；
- BORING 品牌、字体、图标、动画、硬件设计与生产资料。

控制台和固件的配套二进制交付范围另以官方版本说明为准。文档公开不改变品牌资产和第三方依赖的授权。

## 进阶开发

原始设备协议发布后，可作为自行开发通信客户端的参考，使用范围以届时许可为准。独立上位机与控制台扩展是两条不同路径；扩展不能同时充当第二个设备端口持有者。

第三方上位机、跨语言 SDK、自制硬件和特定软件适配暂不承诺开发或维护。遇到超出接口范围的需求，可以描述场景并提出建议，不代表官方承诺实现。

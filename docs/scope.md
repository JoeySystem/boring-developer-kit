## 扩展可以做到什么

用户通过兼容控制台导入本地 Python 扩展，由控制台管理运行、绑定和设备会话。扩展围绕提示词槽位触发，接收语义事件、执行自己的电脑端动作、提出配置建议。也可以修改本轮公开的控制台实现，但该修改不会自动增加设备固件的能力。

以下能力尚不属于 SDK 1.0 的接口承诺：

- 普通按键按下或释放、旋钮转动、摇杆输入的通用事件流；
- 任意绘制屏幕页面或直接控制所有灯光、马达行为；
- 改写设备内部工作模式；
- 由扩展直接写设备配置、执行固件更新或绕过用户确认。

协议中存在某条命令，不代表 SDK 已提供对应方法，也不代表所有固件版本支持它。

## 固件 DIY 范围

当前完整应用固件源码已纳入本次开发包。推荐只改功能层；USB、身份认证、升级、启动回滚、分区、存储与电源底层坚决不要改。详见 [DIY 修改边界](../firmware/DIY-GUIDE.md)。

源码可编译不等于任意 DIY 都可恢复。完整 DIY 安装、恢复官方与功能确认尚未完成实机验收；只有正常连接、认证和 USB 更新仍可用时才具备控制台恢复前提。通用输入及屏幕 API 仍属于后续 SDK 能力。

## 当前保留

- 除单独发布的 `20260916.01` 应用维护镜像外的固件镜像，以及内部生产签发、设备预置、整机验收和标签工具；
- 生产根私钥、设备私钥和 HMAC 密钥、签名与部署凭据、真实生产台账、设备备份和客户数据；
- 硬件设计与生产资料，以及未公开的 BORING 品牌素材、字体素材包、图标和动画设计源文件。

公开根公钥、证书格式、验证代码或公开签名结果不等于泄露私钥。社区控制台使用系统字体，不附内部字库或官方应用图标；产品实拍照片仅供展示，其权利单独保留。

官方控制台 [0.1.13 测试版安装包](install-console.md) 和当前[官方固件维护包](official-firmware-20260916.01.md) 均由 Release 单独提供，不在源码开发包中。源码公开不能替代官方推荐包的实机验收，当前参考版本和实际结果见 [兼容说明](versions.md)。

## 进阶通信开发

独立上位机可参考已发布协议；独立上位机与控制台扩展是不同路径，不能同时争用同一设备端口。第三方客户端、跨语言 SDK、自制硬件和特定软件适配采用 Best Effort，不承诺开发或持续维护。

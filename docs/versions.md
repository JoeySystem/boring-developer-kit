本页只记录开发者仓库的公开交付状态，不列内部候选构建或真实设备记录。

当前没有安装、编译或运行开发包的步骤。文档预览不意味着某个控制台或固件版本已通过开发者交付验收。

## 后续在哪里下载

开发者版本统一通过 [GitHub Releases](https://github.com/JoeySystem/boring-developer-kit/releases) 提供。GitHub 自动生成的仓库源码 ZIP 与开发者工具包是两种文件；当前仓库 ZIP 只有文档。

每次实际发布会写明开发包版本、对应控制台、最低或适用固件、已验证的平台、安装方式、变更与已知限制。平台支持按该次发布说明判断；一个平台通过不代表其他平台通过。

## 更新时怎样判断

先阅读目标版本的兼容说明，再决定是否更新控制台或固件。不要求用户为了开发扩展自行刷入内部候选、编译固件或写入设备身份。

设备固件通过官方维护流程更新。开发包的版本号与控制台、固件版本号各自表示不同的交付物，不能仅因编号相近就认为兼容。

## 发布时间

开发者交付跟随产品稳定性与实际准备情况推进，没有固定发布时间或长期兼容承诺。发生接口调整时，会在实际发布说明中交代影响和必要的适配方法。

仓库文档变化见 [更新记录](../CHANGELOG.md)。

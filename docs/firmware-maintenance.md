# 固件维护与 DIY 边界

当前开发包已加入 [完整应用固件源码](../firmware/README.md)，不包含生产工具、私钥或预编译官方固件。修改电脑端配置与扩展通常无需重编译固件。

**基础模块坚决不要改：USB、身份认证、更新、启动与回滚、分区、存储、电源和硬件引脚。** 逐项可改、慎改与禁止范围见 [DIY 指南](../firmware/DIY-GUIDE.md)。

官方入口要求有效发布签名，旧的未签名 ZIP 需要换用官方签名包。自定义入口使用构建工具生成的 `custom-` 包，不伪装成官方版本，不绕过校验。导入与下载只做检查，确认安装才会通过 USB 写入。

设备仍能正常连接、认证和执行 USB 更新时，具备相应能力的官方控制台可主动查看官方版本、下载并确认恢复，也可以导入官方签名包。恢复允许主动选用较低官方版本，会替换 DIY 功能，不合并代码；改动过配置格式时不承诺配置无损兼容。

完整 DIY 安装和恢复实机流程尚未验收，不保证任意修改都可救回。社区源码已同步到 0.1.46，包含查询、下载、验签、自定义导入和官方恢复逻辑；公开在线源和内置官方发布记录均为空。本次没有更新仓库公开的旧 0.1.13 安装包。安装前必须准备具备所需功能的控制台和匹配设备的官方签名恢复包。

设备无法正常连接或更新时，停止尝试并联系官方支持；不要擦除整片存储、身份数据或使用通用写入工具。

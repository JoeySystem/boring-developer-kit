# 固件维护与自定义固件边界

本仓库发布控制台客户端，**不附完整固件源码、固件压缩包或生产工具**。修改电脑端界面、扩展和自动化通常无需刷固件。

## 官方固件

0.1.24 源码的官方维护入口检查包结构、目标硬件、版本要求、镜像身份和发布者 Ed25519 签名；确认后才开始 USB 传输。发布公钥随源码提供，生产签名私钥保留。

请通过官方渠道获取与设备匹配的签名维护 ZIP。历史无发布者签名的 `.05`、`.07` ZIP 不能直接通过新版官方入口；不要把它们改标为自定义包绕过校验。公开源码的在线固件地址默认留空，不代表网络故障。

## 自定义固件入口

源码包含显式的自定义包导入和额外确认，要求自定义来源标识、`custom-` 构建标识、匹配镜像身份、`built` 状态以及兼容的硬件/控制台版本。不会自动把验签失败的官方包当作自定义包；设备要求固件镜像签名时，会拒绝自定义刷写。

这些检查只判断包是否满足导入条件，不能证明任意修改后的固件可运行或可恢复。当前公开仓库没有提供固件工程或自定义打包工具，不能按本页自行生成可刷固件。

## 恢复与普通用户

**无需拆机即可恢复官方版本的完整用户流程尚未验收，暂不建议普通用户刷入自改固件。** 正常 USB 更新通道仍可工作时，可以通过官方维护入口恢复匹配的签名包；这不是对任意损坏固件的恢复保证。

本设备 BOOT 键位于 PCB 背面，需要拆机。BOOT 恢复属于内部售后操作，不要求用户拆设备。修改造成无法正常连接或无法恢复时，应联系官方处理。

设备身份、认证、分区、启动与更新链路不属于当前用户 DIY 的支持范围。AI 编程生成的改动同样需要审阅与验证；一份说明文档不能代替设备端恢复机制。

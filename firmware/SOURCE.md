# 固件源码来源与交付范围

日期：2026-11-24。目标：BORING MIST，`wired-macro-pad-v1` / `WMP-S3-MATRIX12-POWER-V2`，构建目标 `matrix12-power-v2-codex-usb`，产品版本 `0.3.0-alpha.1`。

参考固件为官方签名的样机权威包 `20261123.01-ga7323e48`，验证等级 `sample-verified`，来源提交 `a7323e48`，原包标记 `git_dirty=false`。它等于 20261118.01（提交 `f1f54815`）加功能中心 SETTINGS 截字修复。本轮把可公开的应用运行源码对齐到该提交，覆盖 20261014.01 至 20261123.01 之间的全部固件改动：蓝牙多主机槽位与私有地址、配对保留、Windows 重连后的按键订阅、第 8 键说话/发送手势、实体按键震动与三档强度、低电保护、外部内存存放配置、启动保护与修复状态、升级后确认、存储损坏降级运行、桌面 Agent 状态来源、双击旋钮切换模式、摇杆异常采样过滤和功能中心标签位置。

公开源码排除了装配对心专用的 Kconfig 选项、定位画面和产线输入自检路径（官方构建同样不启用这些路径）。构建工具只生成 `custom-` 包，因此不能重建出逐字节相同的官方签名镜像；用公开源码实际编译的应用镜像比官方镜像（1,219,856 字节）多 16 字节，差别来自更长的自定义构建编号。该官方包的验证状态是 Power V2 样机验收，不代表所有设备或平台均已验收。

公开范围为应用运行源码、构建配置（含三个故障注入测试配置，只能生成 custom 测试包）、锁定的组件依赖声明、构建与自定义 ZIP 打包工具、ESP-IDF 配对保留补丁、项目内覆盖的 `esp_hid` 组件，以及需要的公开协议常量头。`protocol/generated/protocol_contract.h` 来自同一提交，供固件编译使用；本次不升级社区控制台、SDK 或协议接口版本，固件新增的协议命令暂未写入公开协议文档。

运行时 `.c/.h`、配置和构建工具按选定文件列表复制，不为公开版关闭设备认证、更新校验或电源保护。主机测试只收入能在公开仓库独立运行的部分；依赖内部烧录工具、内部 Console 源码或未公开协议样例的测试未收入。

公开范围包括编译所需的内嵌显示资源；不另附内部设计源文件、字体素材包、产品模型和制造资料。实际许可与品牌使用边界见 [LICENSING.md](../LICENSING.md)。

不包含生产签发/预置工具、签名前核对与发布工具、设备私钥、发布私钥、服务器与部署配置、真实设备证书和台账、用户配置备份、历史二进制或内部维修教程。第三方组件由 ESP-IDF 组件管理器按声明获取，保留各自许可。

源码阅读、构建通过、维护包导入和实体设备功能验收是不同结果。此处源码交付不刷写实体设备、不更新设备身份，也不把 DIY 固件标记成官方发布。另附的[官方签名维护包](../docs/official-firmware-20261123.01.md)与可修改源码分开交付；构建与包检查结果见[验证记录](../docs/firmware-source-verification.md)。历史 `20261118.01`、`20261012.01`、`20260916.01` 源码保留在 Git 历史中。

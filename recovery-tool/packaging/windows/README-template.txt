BORING MIST 固件更新与校准（内部使用）· Windows 64 位
内置固件版本：@BUILD_ID@

用途
给已完成组装的 BORING MIST 写入正式固件、清空蓝牙槽位并校准摇杆，交付前使用。

使用方法
1. 将整个 ZIP 解压到本地短路径文件夹（例如 C:\BORING），退出 BORING Console、串口助手和其他烧录工具。
2. 打开 BORING-MIST-BLE-Recovery 文件夹，双击里面的 BORING-MIST-BLE-Recovery.exe，工具会打开自己的窗口。同一时间只能打开一个。
   不要把 EXE 单独拖出文件夹；需要桌面快捷方式时，右键 EXE 选择“发送到 > 桌面快捷方式”。
3. 将一台正常开机的 BORING MIST 用支持数据传输的 USB 线连接到电脑。
4. 点“开始更新”。工具会写入固件并读回校验、清空全部蓝牙槽位、把第 8 键设为“单击说话（右 Alt/Option + 空格）、双击发送（Enter）”，然后进入摇杆校准。
5. 按窗口提示把摇杆推到上、下、左、右极限，每次松手回中；完成后自动保存，再按提示做四向验收。
6. 显示“本台已完成”后拔下 USB 即可交付，不需要在电脑上配对。接入下一台后点“更新下一台”。
7. 全部完成后关闭窗口或点“退出”（需点两次确认）。

注意
- 不要用本机测试蓝牙连接：一旦配对就会占用一个槽位，使用者拿到后可能以为蓝牙有问题。
- 校准或验收卡住：点“取消校准”（需点两次确认），再点“重新开始”。
- 固件写入期间不能关闭窗口，等写入和读回完成后再关。
- 校准期间关闭窗口：工具会先取消未保存的校准再退出，设备保留原配置。

安全边界
- 只处理正常开机的 BORING MIST；其他 USB 串口设备（CH340、CP210x 等）会被忽略。
- 连接多台 BORING MIST、设备发生变化或验证失败时，工具会停止。
- 工具不会改写设备身份或恢复出厂设置，也不提供拆机刷写。
- 配置只改第 8 键：两个出厂 Profile（Codex macOS / Codex Windows）的第 8 键统一为单击说话、双击发送，并移除全局语音键覆盖；自建 Profile 和其他按键不动。
- 清空蓝牙槽位时逐个清除并读回核对，最后确认三个槽位都为空。

遇到问题
“Windows 拒绝访问”：关闭占用设备连接的程序后重试；仍失败请重新插入 USB。
“工具已经在运行”：切换到已打开的窗口。
窗口无法打开：确认系统已安装 Microsoft Edge WebView2 运行时（Windows 10/11 通常自带）。
记录位置：%LOCALAPPDATA%\Codex Micro Firmware Provisioner\history
每台设备的完整记录（含各阶段耗时）在 history\repair-sessions。

说明
本工具仅供内部使用，未做 Windows 程序签名；首次运行如出现 SmartScreen 提示，选择“仍要运行”。

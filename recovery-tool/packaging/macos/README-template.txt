BORING MIST 固件更新与校准（内部使用）· Apple 芯片 Mac
内置固件版本：@BUILD_ID@

用途
给已完成组装的 BORING MIST 写入正式固件、清空蓝牙槽位并校准摇杆，交付前使用。

开始前
- 完全退出 BORING Console、串口助手和其他烧录工具。
- 请将 BORING MIST 正常开机，并用支持数据传输的 USB 线连接电脑。

使用方法
1. 双击 BORING-MIST-BLE-Recovery；首次打开若被拦截，请右键应用并选择“打开”。
2. 连接设备，等待窗口显示“已识别 1 台 BORING MIST”。
3. 点“开始更新”。工具会写入固件并读回校验、清空全部蓝牙槽位、把第 8 键设为“单击说话（右 Alt/Option + 空格）、双击发送（Enter）”，然后进入摇杆校准。
4. 按窗口提示把摇杆推到上、下、左、右极限，每次松手回中；完成后自动保存，再按提示做四向验收。
5. 显示“本台已完成”后拔下 USB 即可交付，不需要配对。接入下一台后点“更新下一台”。

注意
- 不要用本机测试蓝牙连接：一旦配对就会占用一个槽位。
- 校准或验收卡住：点“取消校准”（需点两次确认），再点“重新开始”。

安全边界
- 只支持正常开机并能通过数据线连接的 BORING MIST。
- 连接多台设备、设备发生变化或验证失败时，工具会停止。
- 工具不会改写设备身份或恢复出厂设置，也不提供拆机刷写。
- 配置只改第 8 键：两个出厂 Profile（Codex macOS / Codex Windows）的第 8 键统一为单击说话、双击发送，并移除全局语音键覆盖；自建 Profile 和其他按键不动。
- 固件更新完成并经过设备验证后，工具才会清空蓝牙槽位；逐个清除并读回核对，最后确认三个槽位都为空。
- 校准结果必须通过保存读回、静止和四个方向检查，窗口才会显示完成。
- 操作记录保存在“~/Library/Application Support/Codex Micro Firmware Provisioner/history”。

说明
本工具仅供内部使用。

# 更新失败时怎么判断

先退出 BORING Console 和其他串口程序，再用本工具。工具只走 USB 数据通道；只有灯闪不能证明这个通道一定失效。

| 看到的情况 | 下一步 |
| --- | --- |
| Mac 上 .app 打不开 | 本版未做 Apple 公证。右键应用选“打开”，或按“隐私与安全性 → 仍要打开”处理，不要关闭系统安全保护。也可以按 README 用源码运行。 |
| Windows 窗口打不开 | 确认整个 ZIP 已解压到短路径（如 `C:\BORING`），EXE 没有被单独拖出文件夹；确认系统有 Microsoft Edge WebView2 运行时（Windows 10/11 通常自带）。 |
| 提示“工具已经在运行” | 切换到已打开的窗口；同一时间只能开一个。 |
| 一直“请连接 BORING MIST” | 用数据线直连，换线或换接口；确认设备已正常开机。灯亮不等于有数据连接。仍找不到时联系售后。 |
| “等待串口释放”或 Windows 拒绝访问 | 关闭占用设备的 Console 或串口程序；仍不行就拔下 USB 再插回。 |
| 识别到多台设备 | 一次只接一台。 |
| 写入中断 | 保持窗口，按提示拔下 USB 等 2 秒再插回，工具会接着读回版本，不需要重新烧录。 |
| 重启或版本回读失败 | 不算完成。检查连接后点“重新开始”，同一台连续失败请记下序列号联系售后。 |
| 清空蓝牙槽位失败 | 固件已写入；检查 USB 后重新开始。不要在本机配对测试，一配对就会占用槽位。 |
| 摇杆校准卡住 | 点“取消校准”（点两次确认），再点“重新开始”。校准期间关闭窗口会先取消未保存的校准，设备保留原配置。 |
| 完成后电脑蓝牙连不上 | 这是预期：槽位已清空。在电脑系统设置里“忽略”旧的 BORING MIST，再重新配对。 |
| Console 显示固件来源未确认 | 在 Console 的固件维护里导入 ZIP 中附带的 `Firmware-BORING-20261123.01.zip`。不要改版本号或公钥。 |

工具不能从完全没有响应的 USB 通道恢复硬件。用户不需要拆机或按 BOOT；无法恢复时由售后继续处理。

## 提供给售后或 AI 的材料

- 系统版本、电脑芯片、BORING Console 版本。
- 工具窗口最后一条错误，以及 history 目录里这次的记录文件（位置见 README）。
- 是否改过固件、是否在写入中断电，不知道就写未知。

记录只存在本机，不自动上传。公开发 Issue 前请隐去本机用户名、目录和设备序列号，不要上传提示词、完整配置备份或其他私人文件。

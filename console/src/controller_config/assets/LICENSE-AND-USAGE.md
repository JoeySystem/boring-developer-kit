# Community build resources

This directory contains BORING-authored generic toggle SVG controls, public
device trust roots and runtime configuration covered by the repository notices.
It does not include the BORING 5R font pack or official application icons.
Community headings use fonts installed on the user's system; no system font
file is redistributed. Qt's standard computer icon is used at runtime.

Public verification keys are not private signing credentials. Brand names
identify the supported product and do not grant a trademark license.
